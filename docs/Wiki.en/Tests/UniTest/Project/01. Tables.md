# Project self-test state-operation tables

## Basis

These tests cover public traversal, replay, continuous execution, and single-use lifetime. The subject is a counter initially equal to 1. `Add`, `Double`, `Stop`, and `Transient` mean +1, ×2, negate and terminate, and +10 and become unsustainable. An independent small arithmetic model supplies expected paths and values.

The same table applies to `ThreadPool` and `Inline`. Existing NUnit tests retain responsibility for worker races and shutdown waiting.

## State-operation table

| State | - | Depth execution | Targeted execution | Continuous execution | Cancel |
| --- | --- | --- | --- | --- | --- |
| Fresh project | - | P01: all bounded paths, **Executed** | P02: specified path only, **Executed** | P03: inspect candidates and select one sustainable continuation, **Executed** | P10: **Unavailable** |
| Execution finished | - | P09: _InvalidOperationException_ | P09: _InvalidOperationException_ | P09: _InvalidOperationException_ | P09: preserve results, allow repeated calls |
| Project cancelled before execution | - | P10: _InvalidOperationException_ | P10: _InvalidOperationException_ | P10: _InvalidOperationException_ | P10: no change |
| External token cancelled, project still fresh | - | P08: finish without user code | P08: finish without user code | P08: finish without user code | X |

## Execution conditions and observations

| ID | Inputs | Expected outcome |
| --- | --- | --- |
| P01 | Depths 0, 1, 3 | Depth 0 still inspects the first candidates. Compare complete successful paths, values, execution counts, model isolation, and terminal branches with an independent oracle. |
| P02 | `Add/Double/Transient/Add`, `Double/Stop` | Validate values and histories at each prefix and compare with the same paths in exhaustive traversal. |
| P03 | Depth 0 and depth 12, seeds 0, 1, 2 | Zero returns only the root. Positive depth inspects four candidates per step and expands only `Add` or `Double`. Repeated runs and both modes produce the same paths for the same seed. Replay a selected path in another project. |
| P04 | Empty generator / terminal Lab only | Depth and continuous execution finish without unnecessary follow-up work. |
| P05 | First Lab fails, all three entry points | Preserve failure and its cause; stop expansion. |
| P06 | Successful and failing siblings, stop-on-failure disabled | Stop the failing branch while executing the successful branch's next action. Failure reports retain failure ancestry. |
| P07 | Iterator throws after yielding a child / missing path ID | Preserve the root error and already created child on generator failure. Propagate unknown-ID errors to the caller. |
| P08 | Pre-cancelled external token | Do not invoke the generator or Actor; reject project reuse. |
| P09 | Complete through each entry point | Reject all entry points on reuse. Repeated cancellation does not mutate earlier results. |
| P10 | Cancel the project before execution | Reject all entry points without running user code. |

The basic table has 15 valid cells, refined into 26 scenarios per execution mode. Mode, seed, and depth are input axes rather than lifetime states.
