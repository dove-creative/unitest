## Independence and reproduction

The expected scenarios are defined by an explicit list of candidate IDs for each state, independently of the existing Expected model.
Expected IDs are not derived from the target Model's state, actual CreateLabs output, or actual child list.
The existing Expected model remains the reference for state results, while the new assertions focus on detecting missing scenarios and unexecuted cases.
Exhaustive execution checks the child set of every parent except those that have terminated or reached the depth limit.
Continuous execution does not fix the selected path itself; it verifies all scenarios that should be generated at each step on that path and that depth 100 is reached.

M01 is an explicit replay path that does not wait for a random seed to reach the boundary by chance.
The existing depths are not increased, and the existing exhaustive and continuous tests using a limit of 10 remain.
Instead of a separate failure test with an incorrect expectation, the tests directly check explicit candidate sets, all required scenarios, Success on every node, and execution counts.
