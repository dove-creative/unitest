## Independent expectations

Each expected axis stores its inclusion/exclusion mode and a five-value allowed bit set. Expectations use input-driven bit unions/differences, never private TestCase fields or actual results. Count, the indexer, and public Confineable queries check current values and all prior snapshots.

Each operation saves the preceding TestCase and a copy of its expectations. Try actions compare predicted success and output, replacing the current value only on success. The deliberately incorrect oracle runs inside an isolated NUnit execution context; its reported failure is checked after restoring the original context.

## Execution and completeness

Bounded exploration has four initial Labs and 11 actions per state. Depth 3 must produce 533 nodes including the root and all 24 state-action identifiers. Every non-root node must explicitly be Success so unexecuted Ready nodes cannot pass silently.

Continuous execution checks maximum depth 16 and a minimum node count. Explicit paths also check length, final first-axis value, and axis count. Boundary results must contain all 11 Lab identifiers. Shared runtime code and existing unit tests remain unchanged.
