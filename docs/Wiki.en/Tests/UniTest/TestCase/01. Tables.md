# TestCase self-test state-action table

## Scope

These tests execute TestCase condition sequences through UniTest Project and Lab. Existing NUnit unit tests remain in place. An independent finite-set model checks public results and preservation of earlier values. The observed domain is 0, 1, 2, 3, 4; mutations use only 0 through 3. Value 4 checks that exclusion conditions retain an open domain.

## States and actions

States describe the first axis: Unbound has no defined axis, Single is one included value, Inclusive is a non-single inclusion condition, and Exclusive is an exclusion condition. Axis count and earlier snapshots are test data rather than states.

Each cell is identified as `TC-state-action`. The table defines 24 cells. Every cell also checks the current value and all saved earlier values against their independent expectations.

| State | - | Append | Set | Confine | Query | TryConfine | TryExcept |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | - | Append included/excluded axis | Include/Exclude | Confine one value | Confineable query | Confineable out overload | ConfineableExcept |
| | - | | | | | | |
| Unbound | - | `[append axis]` | **Inclusive / Exclusive** | **Single** | `[allow all valid values]` | **Single**, true | **Exclusive**, true |
| Single | - | `[preserve axes and append]` | `[union/difference of allowed values]` | **Single** | `[membership of allowed values]` | **Single** if allowed; otherwise false/default output | `[remaining values]` if nonempty; otherwise false/default output |
| Inclusive | - | `[preserve axes and append]` | `[union/difference of allowed values]` | **Single** | `[membership of allowed values]` | **Single** if allowed; otherwise false/default output | `[remaining values]` if nonempty; otherwise false/default output |
| Exclusive | - | `[preserve axes and append]` | `[union/difference of allowed values]` | **Single** | `[values not excluded]` | **Single** if allowed; otherwise false/default output | `[extend exclusions]`, true |

Append is limited to three axes to bound exploration. Query checks single/multiple values, unbound axes, and the indexer's single-inclusion restriction. Failed Try actions do not replace the current value and must return a default out value.

## Boundaries

| ID | Input/action | Expected result |
| --- | --- | --- |
| TC-B01 | Confine with negative or greater-than-Count index | ArgumentOutOfRangeException; preserve original |
| TC-B02 | Include with negative or greater-than-Count index | ArgumentOutOfRangeException; preserve original |
| TC-B03 | Exclude with negative or greater-than-Count index | ArgumentOutOfRangeException; preserve original |
| TC-B04 | Confineable with negative index | ArgumentOutOfRangeException; preserve original |
| TC-B05 | ConfineableExcept with negative or greater-than-Count index | ArgumentOutOfRangeException; preserve original |
| TC-B06 | Confine with null value | ArgumentNullException; preserve original |
| TC-B07 | Include with empty input or null element | ArgumentNullException; preserve original |
| TC-B08 | Exclude with empty input or null element | ArgumentNullException; preserve original |
| TC-B09 | Confineable with empty input or null element | ArgumentNullException; preserve original |
| TC-B10 | ConfineableExcept with empty input or null element | ArgumentException; preserve original |
| TC-B11 | Indexer at Count | ArgumentOutOfRangeException; preserve original |
| TC-F01 | Inject an incorrect expected set | Self-check failure is reported as Node.Failure |

There are 36 cells: 24 state-action cells and 12 boundary/failure controls. Null arrays themselves, negative indexer inputs, and external mutation of constructor arrays are outside this sequence-testing contract.
