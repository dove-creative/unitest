# CompositeLab Self-Test Plan

## Execution structure

Tests reside in `csharp/tests/BlackThunder.UniTest.Tests.Recursion/UniTest/CompositeLabTest.cs`. ScenarioProject creates 51 Labs. Each Lab executes a separate target model and composition. Both execution modes run the complete suite. Completed scenario IDs, child counts, and ProcessCount prevent an empty run from passing.

## Table to code mapping

| Table | Code | Verification |
| --- | --- | --- |
| CL01–CL44, CL46–CL51 | CreateScenarios, ExecuteScenario, ExpectedTrace | Callback order, errors and inner exceptions, final restrictions, metadata and template preservation |
| CL45 | VerifyPersistentExtensions, VerifyComposition | Repeated and branching extension, rerunning each composition, original preservation |
| All | AllScenariosExecute | All 51 scenarios run successfully without cancellation |
| CL03, CL16, CL41, CL45 | SelectedScenarioReplays | Independent ID replay and completion checks |

## Independence and failure handling

Expected traces are string sequences derived from the contract. Restriction outcomes are explicit scenario constants. Target errors are captured and verified by the outer Lab, distinguishing expected target failures from self-test assertion failures.

CL46–CL51 set per-layer expected types through ExpectedByLayer and verify the unmet type and preserved actual exception through ExpectedMissingType and ActorFailure. They follow CL45 so that existing IDs do not change.

The default safe mode applies. Test authoring errors are corrected. Actual runtime defects are recorded and reported, without weakening expectations or changing production code unless the designer approves it.
