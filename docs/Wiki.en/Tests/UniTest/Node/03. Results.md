## Corrections during test authoring

The first integrated build found name collisions between Execute·Cancel inherited by StateProject and the outer test helpers. The method groups passed to Lab were explicitly qualified as NodeTest.Execute·NodeTest.Cancel. This was a compilation error during test authoring; the runtime was not changed.

In the first full execution, 10/11 Node cases passed. The failure control failed because NUnit recorded an assertion failure in the outer test result even when UniTest collected the AssertionException. Only the inner execution was wrapped in NUnit's isolated execution context to correct this.

Context isolation preserves the deliberately incorrect expectation. Isolation remains active until the inner asynchronous execution completes, and outer NUnit assertions run after Dispose restores the original context. This control also passed in the final full execution.
