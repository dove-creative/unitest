## Structure

Implement the 35 items in the [state-operation table](01.%20Tables.md) in [NodeTest.cs](../../../../../tests/BlackThunder.UniTest.Tests.Recursion/UniTest/NodeTest.cs). Outer NUnit executes a UniTest project whose Labs manipulate real Nodes. No project or runtime API is added.

The expected model stores state, input path, and expected children. It computes integer totals and history strings independently, without copying actual Node results. Each Lab checks depth, value, history, status, parent, children, and report ancestry.

## Execution Scope

- BoundedExplorationCoversEveryOperation: Exhaustive depth 4 in both ThreadPool and Inline modes, checking completion, maximum depth, and generated operation kinds.
- ContinuousExplorationPreservesState: Depth 48 with seeds 0, 1, and 2, checking that candidates actually executed.
- RegressionPathsPreserveState: Five paths covering repeated restoration followed by append, failed restoration, terminal restoration, cancellation restoration, and repeated branching. NUnit also compares final state, depth, and value with fixed expectations.
- DetectsIncorrectExpectation: One negative control.

There are 11 NUnit self-test cases. State-path exploration includes integrated verification of Nodes, Labs, and reports.
The [Node unit-test plan](../../Unit/Node/02.%20Plans.md) covers ordinary NUnit construction, execution, restoration, and cancellation synchronization during replay.
