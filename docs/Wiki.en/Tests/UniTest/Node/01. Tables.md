## Scope

These tests combine Node construction, execution, branching, and detached restoration through UniTest paths.
Independent NUnit verification is managed separately in the [Node unit-test table](../../Unit/Node/01.%20Tables.md).

The contract comes from the node construction and history replay section of the [implementation document](../../../02.%20Implementations.md). Expected values use input Lab names and integer deltas. Actual Node state never selects the next test or determines its expected result.

## States and Operations

Root has no Lab; Ready has an unexecuted Lab; Success can continue; Terminal is a successful node that cannot continue; Failure records a Lab failure; Cancelled records cancellation before execution. Add, Fail, and Stop are Ready input variants, not separate states.

## Observations

- N01: Root depth, model value, execution history, parent, and children have their initial values.
- N02–N03: Append replays only preceding Labs; Execute applies the current Lab once. Add adds 1, Stop adds 10, and Fail fails without changing the value.
- N04: Two siblings add 1 and 7 in separate models without changing the parent or existing siblings.
- N05: Restore creates a parentless Ready node while preserving the original graph and earlier reports. Repeated restoration and append after restoration preserve diagnostic ancestry.
- N06: Pre-execution cancellation does not run the Lab. Cancellation remains distinct from failure.
- N07–N12: Rejected calls preserve model, status, and graph.
- N13: An intentionally incorrect expectation must produce a real UniTest failure node observed by outer NUnit.
