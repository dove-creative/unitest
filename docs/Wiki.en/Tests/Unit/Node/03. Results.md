## N14 enhancement history

N14 is an earlier unit test enhancement that replaced elapsed-time cancellation in Append_Executed_Continuable_Idle_Cancelling
with a replay Actor entry signal and a release gate.
The initial run does not wait; cancellation follows confirmed entry, and finally waits for the original task to finish.
The existing result assertions were retained, and a check that the new Lab is not executed was added.

It passed in the integrated run at 2026-11-07 00:03
and was recorded in the corresponding Unit TRX.
It also passed in the 00:11 run above. It asserts two predecessor Lab executions, the original Success and empty children,
a cancellation exception, no returned new node, and no execution of the new Lab.
The record also confirms table/plan/code mapping, removal of Sleep/Delay, LF, final newlines, relative links, code line lengths, and whitespace checks performed at that time.

This detailed record was moved from the earlier self-test document, retaining the N14 identifier.
