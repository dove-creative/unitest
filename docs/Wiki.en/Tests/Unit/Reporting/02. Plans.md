## Verification criteria and limitations

RP01, RP05, and RP09 specify expected node counts; RP05 and RP09 also check nodeId uniqueness.
The before/after JSON comparisons in RP07 and RP08 verify that a previously obtained snapshot from the same object does not change.
The RP11 JSON comparison checks equivalence of parsed values, not identical representations of every character escape.
RP12 checks escaping and UTF-8 encoding of a lone high surrogate; it does not exhaustively test every malformed Unicode combination.
Parameterized verification of both modes in this file is limited to RP03 and RP09.
