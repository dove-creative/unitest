## Target and execution structure

The target fixture is [ModelTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/ModelTest.cs). SetUp creates a new Model, and TearDown releases its reference.
DoExecute invokes the internal execution entry point through reflection and unwraps invocation exceptions. CheckModel compares the three state properties together.
The following mapping documents tests already implemented; it is not a record of a newly performed run.

## Ownership of earlier enhancements

M02 and M03 first set the remaining count to 10 and Continuable=false, verify that precondition, and then reduce the limit.
This Unit document owns the corrections and results for the two cases that start in a terminated state.
The continuous model checks for M01, M04, and M05 remain in the [UniTest plan](../../UniTest/Model/02.%20Plans.md).
