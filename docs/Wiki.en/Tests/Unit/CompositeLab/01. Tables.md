## Contents

## Scope

This table maps the existing CompositeLabTest contracts for composite execution, metadata combination, and Extend.
It distinguishes five contract groups from the 174 NUnit cases after parameter expansion.

## States and actions

| ID | State/input | Action | Current verification | Cases |
| --- | --- | --- | --- | --- |
| UC01 | No model | Execute the composite | Report model setup failure | 1 |
| UC02 | Preparation, action, and assertion succeed in both layers, or one stage fails | Execute the composite | Failure cause and termination, skipped extension Actor, successful normal execution | 7 |
| UC03 | Only the extension declares an expected exception; the Actor throws none | Execute the composite | Check the expected type in MissingExpectedException and termination | 1 |
| UC04 | Sustainability/continuation restrictions and remaining counts on two layers | Execute the composite | OR combination of restrictions, termination at 0, minimum valid count | 144 |
| UC05 | Composite extended to three layers | Run success/failure inputs for each layer pair | Preparation/assertion failures and original Actor handling for three layer pairs | 21 |

## Case composition

UC02 consists of six cases with one failing Arrange, Actor, or Assert across two layers, plus one all-success case. An input that makes the extension Actor fail succeeds because that Actor is never called.
UC04 combines two Boolean restrictions and remaining counts of 10, 0, and -1 for each of two layers: 2⁴ × 3² = 144 cases.
UC05 applies the seven UC02 inputs to three layer pairs, giving 21 cases and a total of 1 + 7 + 1 + 144 + 21 = 174.
Termination timing and the actual reverse order of all Assert calls are counted separately under ToUncontinuableTest in the [Lab unit test table](../Lab/01.%20Tables.md).
