## Existing test structure

The target code is [TestDesignerTest.cs](../../../../../tests/BlackThunder.UniTest.Tests.Unit/TestDesignerTest.cs).
This plan maps existing code to the state table; the table entries describe verification already implemented.
These independent NUnit tests configure ProjectMock's generator for each condition and inspect the internal TestDesigner and prepared queue through reflection.
The default execution mode is ThreadPool.

## Verification limitations

TD02 and TD03 check exception types; they do not assert every diagnostic field for those failures.
TD13 and TD14 check that a second call is rejected without waiting for the first execution to complete;
they do not guarantee that the worker remains at a particular execution point in every case.
TD21–TD24 only check that requesting cancellation after completion does not throw.
Scheduling and shutdown waiting for the full project are covered by separate Project-family tests.
