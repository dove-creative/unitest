## Scope

This table covers the node execution, registration for subsequent design, cancellation, and single-use contracts checked by the existing TestExecutorTest.
It documents existing NUnit coverage rather than adding a new test plan.
The worker's responsibilities are described in the Project execution and shutdown section of [Implementation](../../../02.%20Implementations.md).

Nodes with a Lab start in Ready; nodes without a Lab start in Root.
The node-state checks below include depth 0, absence of parent/child links, Lab reference, ID, model presence, and presence or absence of an exception.

## Counting criteria

There are 24 meaningful state-action cells, each corresponding to one test method without parameters.
Both the number of test methods and the number of NUnit execution cases are therefore 24.
Depth limit, Lab presence, and execution mode are input conditions for each action, not states themselves.
