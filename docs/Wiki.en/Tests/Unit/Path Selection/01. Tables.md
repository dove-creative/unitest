# Shared path selection state table

| ID | Input state | Action | Expected result |
| --- | --- | --- | --- |
| PS01 | Empty history, case variants, Hangul, combining characters, emoji, lone surrogates, and signed seeds | Hash the history. | Raw code units produce a fixed 32-bit value. |
| PS02 | Width one, a negative range, a range requiring rejection sampling, and almost the full Int32 range | Draw a value from the range. | The fixed value is below the exclusive upper bound. |
| PS03 | Candidates with mixed case, Unicode, and duplicate IDs | Sort by ordinal order. | The order matches the fixed expectation and ties preserve generation order. |
| PS04 | The same model, fixed seed, and ordered candidates | Run multiple continuous steps. | Both C# execution modes and TS expand the same sequence of candidate indices. |
