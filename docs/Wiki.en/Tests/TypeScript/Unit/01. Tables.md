# TypeScript Unit tests state-action table

Defines the initial state, action, and expected result for 13 contract rows.

| ID | State | Action or input | Expected result |
| --- | --- | --- | --- |
| TU01 | Model fresh or restricted | Read history and tighten a run limit | History is cumulative and limits never increase. |
| TU02 | TestCase with multiple groups | Refine include or exclude selections | A new case preserves other groups and leaves the original unchanged. |
| TU03 | Lab ready | Resolve asynchronous AAA callbacks | Each stage observes the previous stage's changes and receives the signal. |
| TU04 | Lab executing a stage | Reject Arrange, Act, or Assert | The failure preserves its cause and skips later stages. |
| TU05 | Lab with an expected exception | Throw matching, mismatching, or no error | Only a matching error permits Assert and succeeds. |
| TU06 | Merged or extended Labs | Run metadata and AAA callbacks | Merge runs template then specific callbacks. Extend runs only the original Act and reverses Assert. |
| TU07 | CompositeLab with multiple expectations | Throw an error matching all or only some expectations | All declared expectations must match. Partial matches keep the thrown error as diagnostic context. |
| TU08 | Project ready or partly explored | Explore or replay, then try a second run | Failure stops or permits unrelated branches according to policy. A Project is single use. |
| TU09 | Project not started or Act waiting | Abort externally | Pre-cancellation skips callbacks. Mid-run cancellation waits for Act and does not start another callback. |
| TU10 | Project generating candidates | Throw after yielding a candidate or while creating a model | Recorded generator failure retains the generated branch and cause. Unrecorded construction failure rejects. |
| TU11 | Executed tree with a failed leaf | Detach, rerun, and report | The replayed node restores ancestry and the original graph and captured report remain independent. |
| TU12 | Failure or broken model description | Capture full and failure-only JSON | The filtered report keeps failed nodes and ancestors with the original IDs, plus diagnostic fields and exact string data. |
| TU13 | Shared deterministic input vectors | Hash histories, sample ranges, and sort IDs | All expected signed integers, sampled values, and ordinal indices match. |
