## 해결된 결함

아래 항목은 2026-11-07에 런타임을 수정하고 재실행으로 확인한 내용이다. 미해결 결함으로 다시 집계하지 않는다.
재현 조건과 수정 전후 결과는 [CompositeLab 자체 테스트 결과](UniTest/CompositeLab/03.%20Results.md)에 있다.

### ISSUE-01 CompositeLab의 공유 예상 예외 오판

- 대상: CompositeLab이다.
- 상태: 해결이다. 마지막 확인은 2026-11-07 04:01 한국 시간의 재실행이며 두 실행 모드에서 통과했다.
- 영향: 원본과 확장이 같은 예외를 예상하면, 실제 예외가 발생해도 예상 예외 미발생으로 실패하고 이후 Assert도 실행하지 않았다.
- 원인: 원본 Lab이 예상 예외를 내부에서 처리하여 CompositeLab이 발생 사실을 알 수 없었다.
- 조치: CompositeLab이 원본 Actor의 실제 예외를 받아 모든 계층의 선언과 직접 대조하도록 수정했다.
- 시나리오: CL30·CL31·CL51이다.

### ISSUE-02 CompositeLab의 Exception 선언 오판

- 대상: CompositeLab이다.
- 상태: 해결이다. 마지막 확인은 2026-11-07 04:01 한국 시간의 재실행이며 두 실행 모드에서 통과했다.
- 영향: 원본이 예상 예외를 선언한 조합의 어느 계층에 Exception을 선언하면, 예외가 전혀 발생하지 않아도 모든 Assert를 실행하고 통과했다.
- 원인: 원본 Lab이 예상 예외 미발생을 알리려고 던진 MissingExpectedException을 실제 예외처럼 선언과 대조했다.
- 조치: ISSUE-01과 같은 수정으로 MissingExpectedException을 대조 대상에서 제외했다.
- 시나리오: CL47·CL48이다.

### 예상 예외 계약 변경

- 계약: 선언한 모든 계층의 형식이 실제 예외와 일치해야 성공한다. 2026-11-07에 사용자가 이 방향의 수정을 승인했다.
- 동작 변경: 한 계층만 일치해도 통과하던 조합(CL49·CL50)은 일치하지 않은 첫 계층의 MissingExpectedException으로 실패한다.
- 진단 개선: 실제 예외가 있는 MissingExpectedException은 그 예외를 InnerException으로 보존한다(CL46).
- 수정안 변경: 기존 결과 문서의 bool 반환 수정안은 확장의 다른 선언까지 통과시키는 회귀가 있어 적용하지 않았다.
- 공개 시그니처 변경은 없으며, [CHANGELOG](../../../CHANGELOG.md)에 동작 변경으로 기록했다.

## 기록 관리

이 문서는 검토 항목의 상태와 다음 확인 지점을 관리하고, 실제 명령·결과·TRX·로그는 각 모듈의 결과 문서에서 관리한다.
과거 통합 산출물은 삭제된 상태이므로, 원본 확인은 각 모듈 결과 문서가 연결하는 최신 파일을 사용한다.
항목을 해결할 때는 실제 실행 근거를 해당 모듈 결과 문서에 남긴 뒤 이 문서의 상태와 확인 목록을 갱신한다.
