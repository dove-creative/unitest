실행 명령은 다음과 같다.

```powershell
dotnet test tests/BlackThunder.UniTest.Tests.Unit/BlackThunder.UniTest.Tests.Unit.csproj --configuration Release --no-build --no-restore --filter 'FullyQualifiedName~BlackThunder.UniTest.Tests.Unit.ModelTest' --results-directory docs/Wiki.ko/Tests/Unit/Model --logger 'trx;LogFileName=2026-11-07_02-10-18-unit-model.trx'
```

TRX에는 위 fixture의 사례만 포함되며, 기존 전체 실행의 사례 집합과 중복·누락 없이 대응하는 것을 확인했다.
아래의 이전 실행 결과는 문서 이력으로 유지한다. 과거 전체 TRX·로그는 삭제했으며, 현재 검증의 원본은 위 모듈별 파일을 사용한다.
