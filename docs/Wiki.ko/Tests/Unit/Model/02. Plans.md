## 대상과 실행 구조

대상 fixture는 [ModelTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/ModelTest.cs)이다. SetUp에서 새 Model을 만들고 TearDown에서 참조를 해제한다.
DoExecute는 리플렉션으로 내부 실행 진입점을 호출하고 호출 예외를 풀어 전달한다. CheckModel은 세 상태 속성을 함께 비교한다.
아래는 이미 구현된 테스트를 문서화한 대응표이며, 새 실행을 수행한 기록은 아니다.

## 기존 보강의 소유 위치

M02·M03은 남은 횟수 10과 Continuable=false를 먼저 설정하고 사전 상태를 확인한 뒤 제한을 줄이는 검사이다.
종료 상태에서 시작하는 두 사례의 교정 내용과 결과는 이 Unit 문서가 소유한다.
M01·M04·M05의 연속 모델 검증은 [UniTest 계획](../../UniTest/Model/02.%20Plans.md)에 유지한다.
검증 근거는 [기존 실행 결과](03.%20Results.md)이며, 이번 추가 검증은 [공통 결과](../../Result.md)의 별도 기록을 따른다.
