# Model NUnit 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태와 동작
- 자체 테스트와의 구분

## 범위

기존 ModelTest의 상태 전환·실행 이력·남은 실행 횟수 계약을 역정리한 표이다.
표의 14개 계약 항목과 매개변수를 펼친 NUnit 사례 36개는 서로 다른 집계이다.

## 상태와 동작

| ID | 상태·입력 | 동작 | 현재 검증 내용 | 사례 수 |
| --- | --- | --- | --- | --- |
| UM01 | 초기 상태 | 지속 불가·계속 불가·횟수 제한 전환 | Sustainable·Continuable·RemainingExecutionCount의 조합 확인 | 3 |
| UM02 | 무제한이며 계속 가능 | 한 번 또는 두 번 실행 | 지속 가능 여부 보존, 입력 ID 순서대로 실행 이력 생성 | 4 |

## 자체 테스트와의 구분

M02·M03은 기존 보강 ID를 유지한 NUnit 전용 사례이며, [UniTest Model 문서](../../UniTest/Model/01.%20Tables.md)에서 이 문서로 분리한 항목이다.
M01은 Recursion의 ZeroRemainingCountReplay에 속하므로 UniTest에 남긴다. 반복 경로와 후보 누락 검사는 해당 자체 테스트의 범위이다.
이 표는 현재 단위 테스트의 단언을 설명하며, 모든 입력 경계를 검증한다는 의미는 아니다.
