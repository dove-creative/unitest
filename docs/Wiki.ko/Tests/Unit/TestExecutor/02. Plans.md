# TestExecutor 단위 테스트 대응 계획

- 기존 테스트 구성
- 표와 메서드 대응
- 검증 한계

## 기존 테스트 구성

대상 코드는 [TestExecutorTest.cs](../../../../../tests/BlackThunder.UniTest.Tests.Unit/TestExecutorTest.cs)이다.
기존 코드를 상태표에 대응시킨 문서이며, 표의 항목은 이미 구현된 검증 범위이다.
ProjectMock에 목표 깊이와 실행 모드를 설정하고 내부 TestExecutor와 다음 설계 큐를 리플렉션으로 확인하는 NUnit 테스트이다.
TE16은 Inline, 나머지 항목은 기본 ThreadPool 모드를 사용하는 구성이다.

TE16은 제어 가능한 동기화 컨텍스트로 Inline의 예약 작업을 보류하여 본문 실행 전 취소 지점을 확인한다.

## 검증 한계

TE04는 호출자에게 전달되는 예외 형식을 확인하며 노드의 모든 오류 필드를 확인하는 테스트는 아니다.
TE13·TE14는 첫 호출의 완료를 기다리지 않고 중복 호출을 거부하는 범위이며,
첫 작업이 항상 특정 실행 지점에 머무른다는 보장은 아니다.
TE21–TE24는 완료 후 취소 요청의 예외 없음만 확인한다.
ProcessCount와 전체 프로젝트의 종료 대기·작업자 수거는 이 파일의 직접 단언 범위가 아니다.
