# TestExecutor 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태-동작 표
- 집계 기준

## 범위

기존 TestExecutorTest가 확인하는 노드 실행, 다음 설계 대상 등록, 취소 및 단일 사용 계약의 상태표이다.
새 테스트 계획을 추가하는 작업이 아니라 기존 NUnit 검증 범위를 문서로 정리한 기록이다.
작업자의 책임은 [구현](../../../02.%20Implementations.md)의 프로젝트의 실행과 종료 절에 설명된 범위이다.

Lab이 있는 노드는 Ready, Lab이 없는 노드는 Root에서 시작한다.
아래의 노드 상태 검증에는 깊이 0, 부모와 자식 연결 없음, Lab 참조·ID·모델 존재 및 예외 유무 확인이 포함된다.

## 집계 기준

유의미한 상태-동작 칸은 24개이며 각각 매개변수가 없는 테스트 메서드 하나에 대응한다.
따라서 테스트 메서드 수와 NUnit 실행 사례 수는 모두 24개이다.
깊이 제한, Lab 유무와 실행 모드는 상태 자체가 아니라 각 동작의 입력 조건이다.
