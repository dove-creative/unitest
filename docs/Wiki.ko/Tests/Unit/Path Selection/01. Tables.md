# 공통 경로 선택 상태표

| ID | 입력 상태 | 동작 | 기대 결과 |
| --- | --- | --- | --- |
| PS01 | 빈 이력, 대소문자, 한글, 조합 문자, 이모지, 단독 surrogate와 부호 있는 seed | 이력을 해시한다. | 코드 단위를 변환 없이 처리하고 고정된 32비트 값이 나온다. |
| PS02 | 폭 1, 음수 범위, 재추출이 필요한 범위, 전체 Int32에 가까운 범위 | 범위 안에서 값을 추출한다. | 상한을 제외하고 고정된 값이 나온다. |
| PS03 | 대소문자, 유니코드, 동일 ID가 섞인 후보 | ordinal 순으로 정렬한다. | 고정 순서가 나오며 동일 ID의 생성 순서를 보존한다. |
| PS04 | 동일한 모델과 고정 seed, 생성 순서가 있는 후보 | 여러 단계 연속 실행한다. | C#의 두 실행 모드와 TS가 동일한 후보 인덱스 경로를 확장한다. |
