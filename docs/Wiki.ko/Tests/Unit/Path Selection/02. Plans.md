# 공통 경로 선택 테스트 계획

두 구현은 저장소 루트의 [공통 벡터](../../../../../contracts/selection.json)를 읽는다. 실행 중 기대값을 다시 계산하는 대신 고정값과 비교한다.

| 상태표 | C# 테스트 | 확인 범위 |
| --- | --- | --- |
| PS01 | `HashMatchesSharedVectors` | 해시 값과 UTF-16 단위 처리 |
| PS02 | `RandomMatchesSharedVectors` | 범위 추출과 Int32 경계 |
| PS03 | `OrderingMatchesSharedVectors` | ordinal 순서와 동률의 생성 순서 |
| PS04 | `ContinuousPathMatchesSharedVectors` | Inline·ThreadPool에서 가장 깊게 확장된 부모까지의 실제 경로 |

전체 Release 검증에 이 테스트를 포함한다.
