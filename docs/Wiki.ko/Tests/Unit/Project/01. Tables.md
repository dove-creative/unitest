## 범위

ProjectTest·ProjectSchedulingTest·ProjectShutdownTest·ExecutionModeTest가 직접 검증하는
실행 진입점, 작업 스케줄링, 종료 대기와 실행 모드의 계약이다.
기존 NUnit 사례 63개를 30개 계약 그룹으로 정리한 표이며, 행 수와 매개변수 사례 수는 별개이다.
UniTest의 생성 경로로 확인하는 [Project 자체 테스트](../../UniTest/Project/01.%20Tables.md)와 구분한다.

## 검증 경계

PU01·PU02·PU07·PU10은 단일 후보 SampleProject의 대표 경로를 확인하는 사례이다.
전체 분기 완전성은 PU16과 별도 Project 자체 테스트가 보완하는 범위이다.
PU05는 없는 ID에 대한 반환값, PU22는 시간 제한과 종료 대기이며,
Runner의 모든 반환 경로나 processLimit·실패 JSON 출력까지 검증하는 항목은 아니다.
취소 뒤 Actor 실패가 겹칠 때의 진단 우선순위는 PU19·PU20의 검증 범위에 포함되지 않는다.
