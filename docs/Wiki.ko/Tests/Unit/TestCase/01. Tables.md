# TestCase NUnit 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태와 동작
- 결과 관찰과 한계

## 범위

기존 TestCaseTest의 축 추가·확정·포함·제외 및 조건 가능 여부 검사를 역정리한 표이다.
아홉 계약 항목이 기존 NUnit 메서드 27개에 대응하며 각 메서드는 매개변수 없는 한 사례이다.

## 상태와 동작

| ID | 상태·입력 | 동작 | 현재 검증 내용 | 사례 수 |
| --- | --- | --- | --- | --- |
| UT01 | 조건 축 없음 또는 기존 축 존재 | Append | 새 포함 축 추가, 기존 축 값 유지 | 2 |
| UT02 | 기존 축 또는 끝 위치 | Confine | 첫·끝 축을 단일 포함값으로 교체하거나 새 축 추가 | 3 |
| UT03 | 미정·포함·제외 축 | Include | 포함 축 생성, 포함 집합 합집합, 제외 집합에서 허용값 제거 | 3 |
| UT04 | 미정·제외·포함 축 | Exclude | 제외 축 생성, 제외 집합 합집합, 포함 집합에서 금지값 제거 | 3 |
| UT05 | 포함 축 또는 미정 축 | 단일값 Confineable의 out 오버로드 | 포함된 값은 단일 포함 결과, 미포함값은 false, 미정 축 확장 | 3 |
| UT06 | 제외 축 또는 미정 축 | 단일값 Confineable의 out 오버로드 | 제외되지 않은 값은 단일 포함 결과, 제외값은 false, 미정 축 확장 | 3 |
| UT07 | 포함·제외·미정 축 | 여러 값의 Confineable 조회 | 모든 입력값이 허용될 때만 true, 미정 축은 허용 | 2 |
| UT08 | 포함 축 또는 미정 축 | ConfineableExcept | 차집합·변화 없음·모두 제거 시 false·미정 축의 제외 조건 생성 | 4 |
| UT09 | 제외 축 또는 미정 축 | ConfineableExcept | 제외 집합 합집합·중복·기존 제외값만 입력·미정 축 확장 | 4 |

## 결과 관찰과 한계

기존 검사는 리플렉션으로 TestCases 속성의 축 목록을 읽어 포함 여부와 정의 집합을 비교한다.
Positive·Negative라는 메서드 이름은 주로 포함 축·제외 축의 입력 구분이며, 성공·실패를 그대로 뜻하는 표기가 아니다.
false 결과의 out 기본값, 이전 TestCase 값의 보존, 잘못된 입력 예외를 이 27개가 모두 검증한다고 주장하지 않는다.
공개 API를 통한 독립 집합 기준과 반복 검증은 [UniTest TestCase 표](../../UniTest/TestCase/01.%20Tables.md)의 별도 범위이다.
