## 대상과 관찰 방식

대상 fixture는 [TestCaseTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/TestCaseTest.cs)이다. 각 메서드가 로컬 TestCase를 직접 생성하며 공통 SetUp은 없다.
GetTestCases 보조 메서드가 비공개 TestCases 속성을 리플렉션으로 읽는다. 축 개수·include 플래그·definitions 집합과 반환 bool을 비교하는 구조이다.
아래 표는 현재 구현을 역정리한 것이며 새 실행 계획을 수행했다는 의미가 아니다.

## 집계와 관련 문서

Append_WithNotEmpth 등 실제 코드의 메서드 이름을 그대로 기록한다. 한 메서드 안의 여러 Assert를 별도 NUnit 사례로 세지 않는다.
27개 단위 검사의 기존 결과는 [실행 기록](03.%20Results.md), 반복 경로와 예외 입력 계획은 [UniTest 계획](../../UniTest/TestCase/02.%20Plans.md)에 둔다.
