## 범위

NodeTest와 NodeExtensionTest가 NUnit에서 직접 검증하는 생성·실행·추가·복원·트리 집계 계약이다.
UniTest 경로 생성으로 검증하는 [Node 자체 테스트](../../UniTest/Node/01.%20Tables.md)와 구분한다.
이 문서는 기존 코드를 정리한 표이며 테스트나 도메인 동작을 새로 추가한 것이 아니다.

Root는 Lab 없는 루트, Ready는 미실행 Lab, Success는 계속 가능한 성공, Failure는 실행 실패 상태이다.
기존 메서드 이름의 NullLab·Idle·Executed_NotContinuable은 이 표에서 각각 Root·Ready·Failure에 해당한다.
Executed_NotContinuable 사례는 실패한 Lab을 준비하므로 성공 후 종료되는 별도 상태까지 검증하는 것으로 해석하지 않는다.

## 노드 상태와 동작

| ID | 상태 | - | 동작·입력 | 확인하는 결과 |
| --- | --- | --- | --- | --- |
| NU01 | 생성 전 | - | null 또는 유효한 Lab으로 생성 | 각각 Root 또는 Ready이며 깊이 0, 부모·자식 없음, 모델 존재이다. |
| NU02 | Ready | - | 성공 Lab 실행 | Success, 계속 가능, 예외 없음과 Lab 실행 확인이다. |
| NU03 | Ready | - | 실패 Lab 실행 | Failure, 계속 불가, ExecutionException과 Lab 실행 확인이다. |
| NU04 | Root·Success·Failure | - | Execute 호출 | InvalidOperationException으로 실행 또는 재실행을 거부한다. |
| NU05 | Root·Ready·Success·Failure | - | 유효한 외부 예외와 Cancelled 지정 | Cancelled·계속 불가가 되며 지정 예외의 형식을 보존한다. |
| NU06 | Root·Ready·Success·Failure | - | null 외부 예외 지정 | ArgumentNullException이다. |
| NU07 | Root·Ready·Success·Failure | - | null Lab을 자식으로 추가 | InvalidOperationException이다. |
| NU08 | Ready·Failure | - | 유효한 Lab을 자식으로 추가 | 계속 불가능한 부모이므로 InvalidOperationException이다. |
| NU09 | Root·Success | - | 유효한 Lab 추가 후 미실행 또는 실행 | 부모·자식 연결과 깊이를 유지하며 새 노드는 Ready 또는 Success이다. 새 Lab은 Execute 후에만 실행된다. |
| NU10 | Root·Success | - | 이미 취소된 토큰으로 추가 | OperationCanceledException, 새 노드 미반환, 부모 상태와 빈 자식 보존이다. Success의 선행 Lab은 최초 실행 1회뿐이다. |
| N14 | Success | - | 선행 Lab 재현 Actor 진입 후 취소 | 최초 실행과 재현이 총 2회이며 취소 예외로 생성을 중단한다. 원본 Success·빈 자식, 새 노드 미반환과 새 Lab 미실행을 확인한다. |
| NU11 | Root·Success | - | 두 자식의 생성과 실행 순서를 달리함 | 두 형제가 모두 성공하고 부모에 연결된다. 부모 종류에 따른 선행 Lab 실행 여부도 확인한다. |
| NU12 | Failure | - | 분리·복원 후 새 노드를 재실행 | 복원 노드는 부모 없는 Ready이며 원본 그래프·실패 보고서를 바꾸지 않는다. 복원본이 성공해도 원본 실패는 유지된다. |
| NU13 | 선행 경로가 있는 Failure·복원된 Success | - | 선행 경로 재현 또는 다시 분리·복원 | 원본 형제·자식을 보존하며 복원본의 깊이·이력·진단 조상 연결을 유지한다. 반복 복원은 Ready이다. |
| NU18 | 모든 상태 | - | Afters의 공개 형식 확인 | 읽기 전용 목록이며 자식 추가는 Node만 수행한다. |

N14는 기존 코드 주석과 보강 기록의 식별자를 유지하여 자체 테스트 문서에서 옮긴 항목이다.
NU01~NU13, NU18과 N14는 15개 계약 그룹이며 NodeTest의 매개변수 사례 39개에 대응한다.

## 트리 조회와 집계

| ID | 상태 | - | 동작·입력 | 확인하는 결과 |
| --- | --- | --- | --- | --- |
| NU14 | 루트·중간 노드·리프 | - | GetCount | 자신을 포함한 서브트리 크기이다. 7개 노드 fixture의 결과는 7·2·1·3·1·1·1이다. |
| NU15 | Failure·Cancelled 없는 트리 | - | AllSucceed | true이며 취소 여부는 false이다. fixture에 Ready 노드가 포함되어 있다. |
| NU16 | 취소 또는 실패 노드가 있는 트리 | - | AllSucceed | 취소만 지정한 사례는 true와 취소 여부 true, 실패만 지정한 사례는 false이다. |
| NU17 | 실패 없음·단일 실패·복수 실패 | - | GetFailedReports | 실패 없음은 루트만, 실패가 있으면 필요한 조상과 실패 노드를 원래 NodeId·ParentId 관계로 반환한다. |

트리 조회의 계약 그룹은 4개이고 NodeExtensionTest의 실행 사례는 9개이다.
전체 19개 계약 그룹과 NUnit 실행 사례 48개는 서로 다른 집계이다.

## 검증 경계

상태별 공통 검증은 상태·깊이·부모·자식·Lab·ID·모델 존재·예외 형식·계속 가능 여부이다.
AllSucceed의 true만으로 모든 노드의 실행 완료를 판정하지 않는다.
취소된 부모와 실패한 자식의 혼합 집계는 NU16의 별도 취소·실패 사례에 포함되지 않는다.
파일별 메서드 대응과 취소 동기화는 [계획](02.%20Plans.md), 과거 실행 근거는 [결과](03.%20Results.md)에 기록한다.
