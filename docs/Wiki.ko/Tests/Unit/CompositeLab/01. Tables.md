# CompositeLab NUnit 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태와 동작
- 사례 구성

## 범위

기존 CompositeLabTest의 조합 실행·메타데이터 결합·Extend 계약을 역정리한 표이다.
다섯 계약 항목과 매개변수를 펼친 174개 NUnit 사례를 구분한다.

## 상태와 동작

| ID | 상태·입력 | 동작 | 현재 검증 내용 | 사례 수 |
| --- | --- | --- | --- | --- |
| UC01 | 모델 없음 | 조합 실행 | 모델 설정 실패 보고 | 1 |
| UC02 | 두 계층의 준비·동작·검증 성공 또는 단일 실패 | 조합 실행 | 실패 원인과 종료, 확장 Actor 생략, 정상 실행 성공 | 7 |
| UC03 | 확장만 예상 예외 선언, 실제 Actor 예외 없음 | 조합 실행 | MissingExpectedException의 예상 형식과 종료 확인 | 1 |
| UC04 | 두 계층의 지속·계속 제한 및 남은 횟수 설정 | 조합 실행 | 제한의 OR 결합, 0에서 종료, 유효한 최소 횟수 | 144 |
| UC05 | 세 계층으로 확장한 조합 | 계층 쌍별 성공·실패 입력 실행 | 세 계층 쌍에서 준비·검증 실패 및 원본 Actor 처리 | 21 |

## 사례 구성

UC02는 두 계층의 Arrange·Actor·Assert 각각 한 곳의 실패 6개와 모두 성공 1개이다. 확장 Actor의 실패 입력은 실제로 호출되지 않아 성공하는 사례이다.
UC04는 두 계층 각각의 두 bool 제한과 남은 횟수 10·0·-1을 조합한 2⁴ × 3² = 144개이다.
UC05는 UC02의 일곱 입력을 세 계층 쌍에 적용한 21개이며 1 + 7 + 1 + 144 + 21 = 174개이다.
종료 시점과 모든 Assert의 실제 역순 호출 검사는 [Lab 단위 표](../Lab/01.%20Tables.md)의 ToUncontinuableTest에 별도로 집계한다.
