## 대상 fixture

[LabTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/LabTest.cs)는 CreateLab과 GetTestCases로 단계 조건을 준비하고 각 사례 후 참조를 정리한다.
[LabExtensionTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/LabExtensionTest.cs)는 SetUp에서 단계별 순서 카운터를 초기화하며, 여러 원본을 검사할 때도 카운터를 다시 초기화한다.
[ToUncontinuableTest](../../../../../tests/BlackThunder.UniTest.Tests.Unit/ToUncontinuableTest.cs)는 각 메서드에서 Lab·Model 또는 ProjectMock을 생성한다.
아래는 이미 구현된 실행 구조의 역정리이며 새 테스트 추가 계획이나 새 실행 기록이 아니다.

## 검증 기준

실행 실패 사례는 ExecutionException의 단계와 내부 원인을 검사한다. 확장 사례는 각 콜백의 실제 호출 순번과 실행하지 않은 Actor의 카운터를 비교한다.
종료 사례는 현재 Assert가 실행될 때 모델이 계속 가능한 상태인지 확인하고, 완료 후 종료 여부를 확인한다.
UL14는 ThreadPool·Inline과 Lab·Compact·Composite를 조합하며 설계 호출 수·ProcessCount·자식 수·말단 Success를 확인한다.
통계는 fixture 단위로 한 번만 합산하며 [CompositeLab 단위 문서](../CompositeLab/02.%20Plans.md)에 중복 집계하지 않는다.
기존 근거는 [결과 기록](03.%20Results.md)이다.
