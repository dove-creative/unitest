## 메타데이터 템플릿 전환 전 모듈 단독 실행

이 문서와 같은 폴더에 해당 모듈의 TRX와 실행 로그를 저장했다.

| fixture | 전체 | 통과 | 실패 | 건너뜀 |

| LabExtensionTest | 10 | 10 | 0 | 0 |
| LabTest | 140 | 140 | 0 | 0 |

| 합계 | 172 | 172 | 0 | 0 |

UL16은 전환 전 코드에서 5개 사례가 모두 실패했다.

생성 후 멤버에 대입하던 LabTest의 준비 코드는 생성자와 객체 초기화로 옮겼으며 기대값은 변경하지 않았다.
