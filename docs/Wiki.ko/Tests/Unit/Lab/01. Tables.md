# Lab NUnit 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태와 동작
- 범위 구분

## 범위

LabTest, LabExtensionTest, ToUncontinuableTest의 기존 검증을 모은 표이다. Lab 자체 실행, 확장 조립과 종료 시점의 연동 계약이 범위이다.
18개 계약 항목에 대응하는 NUnit 사례는 141 + 10 + 22 = 173개이다. CompositeLab과 Project를 함께 사용하는 종료 검사는 이 문서에서만 집계한다.

| --- | --- | --- | --- | --- |
| UL01 | 모델 없음 | Lab 실행 | 모델 설정 실패의 ExecutionException과 메시지 | 1 |
| UL02 | 단계별 콜백과 예상 예외 설정 | Lab 실행 | 첫 실패 단계·원인, 모델/메타데이터 전달, 성공 후 제한 확인 | 62 |
| UL03 | 생성자 또는 Arrange에 메타데이터 지정 | Lab 실행 | 전달된 필드와 객체 참조 확인 | 2 |
| UL04 | 제한 없음 또는 유한 제한 | 메타데이터 병합 | 유효한 더 작은 제한 선택 | 6 |
| UL05 | 다양한 콜백·메타데이터 설정 | Lab 복사 | 새 ID, 동일 콜백 참조, 메타데이터 설정 값 보존 | 62 |
| UL06 | 단일 Lab 또는 CompositeLab 원본 | 확장 Lab 결합 | 메타데이터·Arrange 정방향, 원본 Actor만 실행, Assert 역방향 | 2 |
| UL07 | 단일·복합 원본의 혼합 목록 | 목록 확장 | 각 결과의 단계 순서와 원본 Actor 선택 | 1 |
| UL08 | 준비·검증 Lab과 Actor 전용 원본 | 한 개 또는 여러 원본 확장 | 각 원본의 Actor와 확장의 준비·검증 결합 | 2 |
| UL09 | 종료를 선언한 Lab | 현재 실행 완료 | 선언 시점과 무관하게 Assert 후 종료 | 4 |

| UL11 | 세 계층 중 하나가 종료 선언 | CompositeLab 실행 | 모든 Assert를 역순으로 완료한 뒤 종료 | 6 |
| UL12 | 종료 선언과 Assert 실패가 함께 존재 | 단일·복합 Lab 실행 | 실제 실패 보고, 남은 Assert 중단 | 2 |
| UL13 | 원본 또는 확장에서 예상 예외 선언 | 종료 Lab 실행 | 예상 Actor 예외 후에도 필요한 Assert 완료 | 3 |
| UL14 | 종료 Lab을 만드는 프로젝트 | 두 모드에서 깊이 5 실행 | Lab·Compact·Composite의 말단 검증 후 추가 확장 없음 | 6 |
| UL15 | 예상 예외 없음 또는 다른 형식 선언, Actor가 호출한 코드에서 예외 발생 | Lab 실행 | Act 실패의 내부 예외 형식과 원래 호출 위치의 스택 추적 보존 | 2 |
| UL16 | 생성된 Lab | ID와 콜백 멤버 확인 | Id·SetMetadata·Arranger·Actor·Asserter가 생성 전용임을 확인 | 5 |
| UL17 | 콜백을 가진 Lab과 템플릿 | 선택 항목별 병합 후 실행 | 선택한 템플릿 콜백이 먼저 실행되고 원본 Lab은 변하지 않음 | 5 |
| UL18 | 생성된 Lab | 메타데이터 템플릿의 공개 형식 확인 | 쓰기 가능한 멤버가 없는 읽기 전용 인터페이스임을 확인 | 1 |

## 범위 구분

UL02와 UL05는 31개 단계 조건 조합에 생성자 설정 유무를 적용하여 각각 62개 사례이다.
UL04의 입력은 (-1,-1), (-1,3), (3,-1), (1,10), (10,1), (0,5)이다.
UL09의 종료 선언 시점은 Template·Arrange·Act·Assert이며, UL11은 세 계층과 템플릿·Assert 시점의 조합이다.
실제 반복 경로와 독립 시나리오 목록 검사는 [UniTest Lab 표](../../UniTest/Lab/01.%20Tables.md)의 별도 범위이다.
