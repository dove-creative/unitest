## 기존 테스트 구성

대상 코드는 [TestDesignerTest.cs](../../../../../tests/BlackThunder.UniTest.Tests.Unit/TestDesignerTest.cs)이다.
기존 코드를 상태표에 대응시킨 계획 문서이며, 표의 항목은 이미 구현된 검증 범위이다.
ProjectMock의 생성 함수를 조건별로 설정하고 내부 TestDesigner와 준비 큐를 리플렉션으로 확인하는 독립 NUnit 테스트이다.
기본 실행 모드는 ThreadPool이다.

## 검증 한계

TD02·TD03은 예외 형식을 확인하며 해당 실패의 진단 필드 전체를 단언하는 테스트는 아니다.
TD13·TD14는 첫 실행의 완료를 기다리지 않고 두 번째 호출이 거부되는지 확인하는 범위이며,
모든 경우에 작업자가 특정 실행 지점에 머무른다는 보장은 아니다.
TD21–TD24는 완료 후 취소 요청이 예외를 던지지 않는지만 확인한다.
전체 프로젝트의 스케줄링과 종료 대기는 별도 Project 계열 테스트의 범위이다.
