# TestDesigner 단위 테스트 상태-동작 표

## 목차

- 범위
- 상태-동작 표
- 집계 기준

## 범위

기존 TestDesignerTest가 확인하는 Lab 생성, 자식 노드 준비, 취소 및 단일 사용 계약을 정리한 문서이다.
새 테스트의 작성 지시가 아니라 이미 존재하는 NUnit 단위 테스트의 검증 범위를 역으로 정리한 기록이다.
구성 요소의 책임은 [구현](../../../02.%20Implementations.md)의 프로젝트의 실행과 종료 절을 기준으로 한다.

부모 조건은 Root 또는 실행을 마친 Success 노드이다. 자식 재현 실패 조건은 Success 부모만 사용한다.
아래의 '부모 유지'는 상태·깊이·부모와 자식 연결·예외·Lab 참조·ID·모델 존재를 확인하는 범위이다.

## 집계 기준

표의 유의미한 상태-동작 칸은 24개이며 테스트 메서드도 24개이다.
부모 조건 두 가지를 전개한 메서드 19개와 Success 부모만 사용하는 메서드 5개를 합쳐 NUnit 실행 사례는 43개이다.
TD15와 TD16은 취소 이후 생성 결과가 있는 경우와 없는 경우의 현재 검증 계약을 구분한 칸이다.
