# TestCase 자체 테스트 상태-동작 표

## 범위

TestCase의 조건 조합을 UniTest의 Project와 Lab으로 연속 실행하는 테스트이다. 기존 NUnit 단위 테스트를 유지하고, 공개 API 결과와 이전 값의 보존을 별도 유한 집합 모델로 검증한다. 검사 값은 0, 1, 2, 3, 4이며, 변경 입력에는 0부터 3까지만 사용한다. 값 4는 제외 조건의 열린 범위를 확인하는 대조 값이다.

## 상태와 동작

선택한 첫 번째 축의 조건을 상태로 구분한다. 축 개수와 이전 값 목록은 입력·검증 자료이다. `Unbound`는 선택할 축이 없는 조건 미정 상태, `Single`은 단일 포함 조건, `Inclusive`는 단일 값으로 확정되지 않은 포함 조건, `Exclusive`는 제외 조건이다.

각 칸의 식별자는 `TC-상태-동작`이다. 아래 표는 24개 검증 칸을 정의한다. 모든 칸은 실행 후 현재 조건과 저장된 이전 조건이 기대값을 유지하는지도 확인한다.

| 상태 | - | Append | Set | Confine | Query | TryConfine | TryExcept |
| --- | --- | --- | --- | --- | --- | --- | --- |
| | - | 포함·제외 축 추가 | Include·Exclude | 지정 값으로 확정 | Confineable 조회 | Confineable의 out 오버로드 | ConfineableExcept |
| | - | | | | | | |
| Unbound | - | `[축 추가]` | **Inclusive / Exclusive** | **Single** | `[모든 유효 값 허용]` | **Single**, true | **Exclusive**, true |
| Single | - | `[기존 축 보존·새 축 추가]` | `[허용 집합 합집합·차집합]` | **Single** | `[허용 값 포함 여부]` | 허용 시 **Single**, 아니면 false·기본 결과 | 잔여 값이 있으면 `[제외 결과]`, 아니면 false·기본 결과 |
| Inclusive | - | `[기존 축 보존·새 축 추가]` | `[허용 집합 합집합·차집합]` | **Single** | `[허용 값 포함 여부]` | 허용 시 **Single**, 아니면 false·기본 결과 | 잔여 값이 있으면 `[제외 결과]`, 아니면 false·기본 결과 |
| Exclusive | - | `[기존 축 보존·새 축 추가]` | `[허용 집합 합집합·차집합]` | **Single** | `[제외되지 않은 값 허용]` | 허용 시 **Single**, 아니면 false·기본 결과 | `[제외 조건 추가]`, true |

Append는 세 축까지만 허용하여 경로 크기를 제한한다. Query는 단일·복수 값 조건, 미정 축, 인덱서의 단일 포함 조건 제한을 검증한다. 실패한 Try 동작은 현재 값을 교체하지 않으며 out 결과가 기본값인지 확인한다.

## 경계 조건

| ID | 입력·동작 | 기대 결과 |
| --- | --- | --- |
| TC-B01 | Confine의 음수·Count 초과 인덱스 | ArgumentOutOfRangeException, 원본 보존 |
| TC-B02 | Include의 음수·Count 초과 인덱스 | ArgumentOutOfRangeException, 원본 보존 |
| TC-B03 | Exclude의 음수·Count 초과 인덱스 | ArgumentOutOfRangeException, 원본 보존 |
| TC-B04 | Confineable의 음수 인덱스 | ArgumentOutOfRangeException, 원본 보존 |
| TC-B05 | ConfineableExcept의 음수·Count 초과 인덱스 | ArgumentOutOfRangeException, 원본 보존 |
| TC-B06 | Confine의 null 값 | ArgumentNullException, 원본 보존 |
| TC-B07 | Include의 빈 입력·null 요소 | ArgumentNullException, 원본 보존 |
| TC-B08 | Exclude의 빈 입력·null 요소 | ArgumentNullException, 원본 보존 |
| TC-B09 | Confineable의 빈 입력·null 요소 | ArgumentNullException, 원본 보존 |
| TC-B10 | ConfineableExcept의 빈 입력·null 요소 | ArgumentException, 원본 보존 |
| TC-B11 | Count 위치의 인덱서 | ArgumentOutOfRangeException, 원본 보존 |
| TC-F01 | 실제 값과 다른 기대 집합을 주입 | 자체 검증 실패가 Node.Failure로 보고됨 |

전체 범위는 상태-동작 24칸과 경계·실패 대조 12칸을 합한 36칸이다. null 배열 자체, 인덱서의 음수 입력, 생성자에 전달한 배열의 외부 변경은 이 연속 조합 테스트의 계약 범위에 포함하지 않는다.
