## 빌드와 전체 실행

솔루션 Release 빌드와 테스트 작성 보완 후 Recursion 프로젝트 Release 빌드는 모두 경고 0개·오류 0개로 완료하였다. 전체 테스트 명령은 다음과 같다.

```powershell
dotnet test BlackThunder.UniTest.sln --configuration Release --no-build --no-restore -m:1 --logger trx
```

전체 결과는 627개 중 625개 통과·2개 실패이다. 기존 테스트는 598/598, 신규 TestCase는 10/10, Node는 11/11, Project는 2/2, CompositeLab은 4/6이다. 남은 두 실패는 CompositeLab의 CL30·CL31 계약 문제를 두 실행 모드에서 검출한 결과이며, TestCase 자체 테스트 실패가 아니다. 사용자 결정에 따라 대상 런타임을 수정하지 않고 테스트와 결과를 보존하였다.

Recursion 프로젝트 전체는 37개 중 35개 통과·2개 실패이며 소요 시간은 약 3초이다. 당시 원본 로그·TRX는 삭제했으며 이 결과는 문서 이력으로 유지한다.

## 테스트 작성 중 보완

TC-F01에서 의도적으로 발생시킨 NUnit 검증 실패는 UniTest가 예외를 포착해도 바깥 NUnit 결과에 기록되었다. 대상 런타임 결함이 아니라 실패 대조의 실행 문맥 문제이다. 내부 자체 테스트를 NUnit의 IsolatedContext에서 실행하고, 문맥을 복구한 뒤 Node.Failure와 AssertionException을 검증하도록 수정하였다. 틀린 기대값을 실제로 비교하는 검증은 유지하였다.
