## 독립성과 재현

기대 시나리오의 기준은 기존 Expected 모델과 별도로 명시한 상태별 후보 ID 목록이다.
대상 Model의 상태나 실제 CreateLabs 출력, 실제 자식 목록으로 예상 ID를 만들지 않는다.
기존 Expected 모델은 상태 결과의 기준으로 유지하고, 새 검증은 시나리오 누락과 미실행 탐지에 집중한다.
전수 실행에서는 깊이 제한에 도달하거나 종료한 경우를 제외한 모든 부모의 자식 집합을 확인한다.
연속 실행은 선택된 경로 자체를 고정하지 않고, 선택한 경로의 각 단계에서 생성되어야 할 전체 시나리오와 깊이 100 도달을 검증한다.

M01은 무작위 시드가 우연히 경계에 도달하기를 기다리지 않는 명시적 재현 경로이다.
기존 깊이를 늘리지 않으며, 제한값 10을 사용하는 기존 전수·연속 테스트도 유지한다.
거짓 기대값을 넣은 별도 실패 테스트 대신, 명시적 후보 집합·전체 필수 시나리오·모든 노드의 Success·실행 수를 직접 확인한다.
