# Model 기존 테스트 보강 상태-동작 표

## 목차

- 범위
- 상태-동작 표
- 실행 확인 기준

## 범위

기존 Model 자체 테스트의 남은 실행 횟수 경계와 실제 실행 보장을 보강하는 표이다.
기존 상태별 시나리오와 실행 깊이는 유지하며, 도메인 코드는 변경하지 않는 범위이다.

## 상태-동작 표

| 상태 | - | 동작 | 입력 조건 | 기대 결과 | 계획 |
| --- | --- | --- | --- | --- | --- |
| 계속 가능한 횟수 제한 상태 | - | 남은 횟수 감소 설정 | 1 → 0 | 지속 불가·계속 불가, 기대 모델도 같은 상태 | M01 |
| 새 자체 테스트 프로젝트 | - | 깊이 제한 전수 실행 | 깊이 6, 두 실행 모드 | 각 상태의 예상 시나리오와 전체 필수 시나리오 전부 실행, 각 노드 성공, 실행 수 일치 | M04 |
| 새 자체 테스트 프로젝트 | - | 연속 실행 | 깊이 100, 시드 0·1·2, 두 실행 모드 | 선택한 경로의 각 단계에서 예상 시나리오 전부 실행, 깊이와 실행 수 일치 | M05 |

유의미한 표의 칸은 3개이다. 실행 모드와 시드는 상태가 아니라 동일 계약의 입력 조건이다.
M02·M03은 NUnit 전용 항목이므로 [Unit Model 표](../../Unit/Model/01.%20Tables.md)로 분리하였다.
M01은 Recursion의 ZeroRemainingCountReplay이며 이 자체 테스트 범위에 유지한다.

## 실행 확인 기준

예상 시나리오는 생성기의 실제 출력을 읽어 계산하지 않는다.
기존 Expected 모델과 별도로 명시한 상태별 후보 ID 목록을 사용하며, 전수 실행의 필수 시나리오 집합도 별도로 명시한다.
루트 이외의 모든 결과는 Success여야 하며, 깊이·실행 횟수·실행 이력이 경로와 일치해야 한다.
빈 트리, 누락된 시나리오, Ready 상태의 미실행 노드를 성공으로 인정하지 않는다.
