## 최근 모듈 단독 실행

실행 명령은 다음과 같다.


## 실행 명령과 기록

저장소 루트에서 수행한 명령은 다음과 같다.

```text
dotnet build BlackThunder.UniTest.sln --configuration Release --no-restore -m:1
dotnet test BlackThunder.UniTest.sln --configuration Release --no-build --no-restore -m:1 --logger trx
```

테스트 명령은 기존 testhost의 샌드박스 제약 때문에 권한 상승으로 실행한 기록이다.
전체 테스트의 종료 코드는 미해결 CompositeLab 실패에 따른 1이다.

위 명령은 당시 실행 명령을 현재 프로젝트별 기본 출력 위치에 맞춰 정리한 표기이다. 과거 원본 TRX·로그는 삭제하였다.
