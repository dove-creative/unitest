## 명령과 산출물

```powershell
dotnet build BlackThunder.UniTest.sln --configuration Release --no-restore -m:1
dotnet build tests/BlackThunder.UniTest.Tests.Recursion/BlackThunder.UniTest.Tests.Recursion.csproj --configuration Release --no-restore -m:1
dotnet test BlackThunder.UniTest.sln --configuration Release --no-build --no-restore -m:1 --logger trx
```

두 빌드는 모두 경고·오류 없이 통과했다. 마지막 명령은 위 결함 때문에 종료 코드 1을 반환했다. 이 환경에서는 샌드박스 안의 testhost 연결 제한이 앞선 작업에서 확인되어, 테스트는 승인된 샌드박스 밖 실행을 사용했다.

당시 원본 산출물은 삭제했으며, P01–P10의 표·계획·함수 대응과 26개 고유 시나리오 ID의 실행 확인 결과는 문서 이력으로 유지한다.
