# CompositeLab 자체 테스트 상태-동작 표

## 범위

CompositeLab과 Extend의 실행 순서, 실패 위치, 예상 예외, 실행 제한 및 원본 보존을 검증한다. 기존 NUnit 단위 테스트를 유지하며, 별도 UniTest 프로젝트가 아래 51개 시나리오를 모두 실행한다.

## 상태와 동작

준비 상태는 실행 가능한 새 모델과 조합을 가진 상태이다. 실행 중에는 메타데이터 생성·준비·원본 동작·역순 검증 단계가 존재하며, 오류는 후속 단계를 중단한다. 성공 후에는 제한에 따라 계속 가능·지속 불가·종료 상태가 된다. 계층 위치와 계층 수는 상태가 아닌 입력 조건이다.

| ID | 상태 | 동작과 입력 | 기대 결과 | 칸 수 |
| --- | --- | --- | --- | --- |
| CL01–CL03 | 준비 | 확장 1·2·3개 실행 | 준비 정순, 원본 Act 1회, 검증 역순, 이력 1개 | 3 |
| CL04–CL07 | 메타데이터 생성 중 | 4개 계층 각각에서 실패 | 해당 생성까지 실행, Arrange 오류, 후속 단계 없음 | 4 |
| CL08–CL11 | 준비 실행 중 | 4개 계층 각각에서 실패 | 해당 Arrange까지 실행, 후속 단계 없음 | 4 |
| CL12 | 동작 실행 중 | 원본 Act 실패 | Act 오류, 검증 없음 | 1 |
| CL13–CL16 | 검증 실행 중 | 4개 계층 각각에서 실패 | 역순으로 해당 Assert까지 실행 | 4 |
| CL17 | 준비 | 확장 계층의 Actor가 모두 실패하도록 설정 | 확장 Actor를 호출하지 않고 성공 | 1 |
| CL18–CL21 | 동작 실행 중 | 4개 계층 각각에 일치하는 예상 예외 | 예상 예외를 받아들이고 모든 Assert 실행 | 4 |
| CL22–CL25 | 동작 실행 중 | 4개 계층 각각의 예상 예외 미발생 | MissingExpectedException, 검증 없음 | 4 |
| CL26–CL29 | 동작 실행 중 | 4개 계층 각각의 예상 예외와 다른 예외 | 원래 예외 보존, 검증 없음 | 4 |
| CL30–CL31 | 동작 실행 중 | 원본과 확장 1 또는 3에 같은 예상 예외 | 일치하는 실제 예외를 받아들이고 검증 완료 | 2 |
| CL32–CL35 | 준비 | 4개 계층 각각의 지속 불가 제한 | 모든 검증 후 지속 불가, 계속 가능 | 4 |
| CL36–CL41 | 준비·준비 실행·검증 실행 | 원본·마지막 확장에서 종료 제한 설정 | 현재 검증 모두 완료 후 종료 | 6 |
| CL42 | 준비 | 계층별 횟수 -1·7·3·5 | 가장 작은 유효 제한 3 | 1 |
| CL43 | 준비 | 계층별 횟수 6·0·4·-1 | 검증 완료 후 남은 횟수 0, 종료 | 1 |
| CL44 | 남은 횟수 2 | 계층별 횟수 5·3·8·-1 | 이번 실행 차감 후 1 유지 | 1 |
| CL45 | 조합 생성됨 | 반복 Extend와 같은 확장으로 형제 조합 생성 | 원본과 이전 조합 보존, 각 경로의 ID와 순서 유지 | 1 |
| CL46 | 동작 실행 중 | 원본 IOE·확장 1 AE 선언, 원본 Actor가 IOE 발생 | AE의 MissingExpectedException, 실제 예외 보존, 검증 없음 | 1 |
| CL47 | 동작 실행 중 | 원본만 Exception 선언, 예외 미발생 | Exception의 MissingExpectedException, 검증 없음 | 1 |
| CL48 | 동작 실행 중 | 원본 IOE·확장 1 Exception 선언, 예외 미발생 | IOE의 MissingExpectedException, 검증 없음 | 1 |
| CL49 | 동작 실행 중 | 확장 1 IOE·확장 2 AE 선언, 원본 Actor가 IOE 발생 | AE의 MissingExpectedException, 실제 예외 보존, 검증 없음 | 1 |
| CL50 | 동작 실행 중 | 원본 IOE·확장 1 AE 선언, 원본 Actor가 AE 발생 | IOE의 MissingExpectedException, 실제 예외 보존, 검증 없음 | 1 |
| CL51 | 동작 실행 중 | 원본 Exception·확장 1 IOE 선언, 원본 Actor가 IOE 발생 | 기반 형식 선언도 일치로 받아들이고 모든 Assert 실행 | 1 |

IOE는 InvalidOperationException, AE는 ArgumentException이다.
예상 예외를 선언한 모든 계층의 형식이 실제 예외와 일치해야 성공한다. 어느 계층과도 일치하지 않는 실제 예외는 그대로 보존하고, 일부 계층만 일치하면 일치하지 않은 첫 계층의 MissingExpectedException으로 실패한다.

예상 호출 이력은 고정된 정순·역순 계약에서 별도로 작성한다. 실제 CompositeLab의 내부 목록이나 MetadataGroup으로 예상값을 계산하지 않는다.
