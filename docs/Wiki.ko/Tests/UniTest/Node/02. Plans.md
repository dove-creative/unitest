# Node 자체 테스트 계획

## 목차

- 구성
- 표와 코드 대응
- 실행 범위
- 결과 기록

## 구성

[상태-동작 표](01.%20Tables.md)의 35개 항목을 [NodeTest.cs](../../../../../tests/BlackThunder.UniTest.Tests.Recursion/UniTest/NodeTest.cs)에 구현한다. 외부 NUnit이 UniTest 프로젝트를 실행하고, 내부 Lab이 실제 Node를 조작한다. 새 프로젝트나 런타임 API는 추가하지 않는다.

기대 모델은 현재 상태, 입력 경로와 자식 목록을 보관한다. 정수 합과 문자열 이력을 직접 계산하며, Node의 실제 결과로 기대값을 갱신하지 않는다. 각 Lab 뒤에 깊이·값·이력·상태·부모·자식·리포트 경로를 검증한다.

## 표와 코드 대응

| ID | 코드 | 검증 |
| --- | --- | --- |
| N01 | StateModel, AssertCurrent | 루트 초기 상태 |
| N02 | Append | 세 입력 Lab의 추가와 선행 경로 재현 |
| N03 | Execute | 성공·실패·종료 결과 |
| N04 | Branch | 형제·부모 모델 분리 |

| N07~N12 | Reject | 잘못된 동작·입력·취소된 토큰의 거부와 상태 보존 |
| N13 | DetectsIncorrectExpectation | 잘못된 기대값을 실제 실패로 관찰 |

## 실행 범위

- BoundedExplorationCoversEveryOperation: ThreadPool·Inline 각각 깊이 4 전체 탐색이다. 모든 생성 노드의 완료 상태, 최대 깊이와 동작 종류를 확인한다.
- ContinuousExplorationPreservesState: 시드 0·1·2로 각각 깊이 48 연속 실행이다. 후보 실행이 실제로 수행되었는지 확인한다.
- RegressionPathsPreserveState: 반복 복원 후 자식 추가, 실패 복원, 종료 복원, 취소 복원, 반복 분기의 다섯 경로이다. 마지막 상태·깊이·값을 NUnit에서도 고정 기대값과 비교한다.
- DetectsIncorrectExpectation: 실패 대조군 1개이다.

자체 테스트의 NUnit 실행 항목은 총 11개이다. 상태 경로 탐색은 노드·Lab·리포트의 통합 검증을 포함한다.
일반 NUnit의 생성·실행·복원과 재현 중 취소 동기화는 [Node 단위 테스트 계획](../../Unit/Node/02.%20Plans.md)에 있다.

## 결과 기록

실행 결과와 발견한 문제는 [결과 기록](03.%20Results.md)에 남긴다. 테스트 작성 오류는 수정하고, 실제 런타임 계약 문제는 런타임을 변경하지 않고 보고한다.
