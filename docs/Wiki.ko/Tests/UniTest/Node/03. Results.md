## 테스트 작성 중 수정

최초 통합 빌드에서 StateProject가 상속한 Execute·Cancel과 외부 테스트 도우미의 이름이 충돌하였다. Lab에 전달하는 메서드 그룹을 NodeTest.Execute·NodeTest.Cancel로 명시하여 수정하였다. 테스트 작성 단계의 컴파일 오류이며 런타임은 변경하지 않았다.

최초 전체 실행에서 Node 항목은 10/11 통과하였다. 실패 대조군은 UniTest가 AssertionException을 수집해도 NUnit이 외부 테스트 결과에 검증 실패를 기록하여 실패하였다. 내부 실행만 NUnit의 격리된 실행 컨텍스트로 감싸 수정하였다.

컨텍스트 격리는 의도적인 잘못된 기대값을 유지한다. 내부 비동기 실행 완료까지 격리를 유지하며, 외부 NUnit 검증은 Dispose로 원래 컨텍스트를 복원한 뒤 수행한다. 최종 전체 실행에서 이 대조군도 통과하였다.
