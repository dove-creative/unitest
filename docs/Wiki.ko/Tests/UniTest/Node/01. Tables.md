# Node 자체 테스트 상태-동작 표

## 목차

- 범위
- 상태와 동작
- 관찰 기준

## 범위

Node의 생성, 실행, 분기와 분리·복원을 UniTest 경로로 조합하는 테스트이다.
독립 NUnit 검증은 [Node 단위 테스트 표](../../Unit/Node/01.%20Tables.md)에서 별도로 관리한다.

기준은 [구현 문서](../../../02.%20Implementations.md)의 노드 생성과 이력 재현 계약이다. 기대 상태는 입력 Lab의 이름과 정수 변화량으로 계산한다. 대상 Node의 상태를 다음 테스트 선택이나 기대값 계산에 사용하지 않는다.

## 상태와 동작

Root는 Lab 없는 루트, Ready는 아직 실행하지 않은 Lab, Success는 계속 가능한 성공, Terminal은 계속 불가능한 성공, Failure는 Lab 실패, Cancelled는 실행 전 취소 상태이다. Ready의 Add·Fail·Stop은 입력 변형이며 별도 상태가 아니다.

| 상태 | - | Append | Execute | Restore | Branch | Cancel | RejectNull | RejectId | CancelledAppend |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | - | Add·Fail·Stop | | | 두 형제 생성·실행 | 실행 전 취소 기록 | null Lab | 구분자 포함 ID | 취소된 토큰 |
| | - | | | | | | | | |
| Root | - | **Ready**, N02 | _InvalidOperation_, N07 | _InvalidOperation_, N09 | `[독립 모델]`, N04 | X | _InvalidOperation_, N10 | _Argument_, N11 | _OperationCanceled_, N12 |
| Ready | - | _InvalidOperation_, N08 | **Success / Failure / Terminal**, N03 | **Ready**, N05 | X | **Cancelled**, N06 | X | X | X |
| Success | - | **Ready**, N02 | _InvalidOperation_, N07 | **Ready**, N05 | `[독립 모델]`, N04 | X | _InvalidOperation_, N10 | _Argument_, N11 | _OperationCanceled_, N12 |
| Terminal | - | _InvalidOperation_, N08 | _InvalidOperation_, N07 | **Ready**, N05 | X | X | X | X | X |
| Failure | - | _InvalidOperation_, N08 | _InvalidOperation_, N07 | **Ready**, N05 | X | X | X | X | X |
| Cancelled | - | _InvalidOperation_, N08 | _InvalidOperation_, N07 | **Ready**, N05 | X | X | X | X | X |

입력 변형을 포함한 유효 칸은 33개이다. N01의 초기 상태 검증과 N13의 잘못된 기대값 검출 대조군을 더해 계획 항목은 35개이다. 생성된 경로 수는 이 칸 수와 별개이다.

## 관찰 기준

- N01: 루트 깊이·모델 값·실행 이력·부모·자식이 초기값이다.
- N02·N03: Append는 선행 경로만 재현하고, Execute는 현재 Lab을 한 번 반영한다. Add는 1, Stop은 10을 더하며 Fail은 값을 변경하지 않고 실패한다.
- N04: 두 형제는 각각 1과 7을 더한 별도 모델을 사용하며 부모 모델과 기존 형제를 변경하지 않는다.
- N05: 복원은 부모가 없는 Ready 노드를 만들고 원본 그래프와 이전 리포트를 보존한다. 반복 복원과 복원 노드의 자식 추가도 진단 조상 경로를 보존한다.
- N06: 실행 전 취소는 Lab을 실행하지 않는다. 취소와 실패는 서로 다른 상태이다.
- N07~N12: 거부된 호출은 모델, 상태와 그래프를 변경하지 않는다.
- N13: 의도적으로 틀린 기대값은 외부 NUnit 테스트에서 실제 UniTest 실패 노드로 확인한다.
