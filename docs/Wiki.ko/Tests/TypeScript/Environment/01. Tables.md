# TypeScript 환경 및 패키지 테스트 상태-동작 표

3개 계약 행의 초기 상태, 동작과 기대 결과를 정의한다.

| ID | 상태 | 동작·입력 | 확인하는 결과 |
| --- | --- | --- | --- |
| TE01 | ESM 빌드 및 브라우저 엔진 준비 | 고정 선택 벡터와 비동기 탐색을 실행한다. | Chromium, Firefox, WebKit에서 같은 기대값을 확인하고 정상 결과를 얻는다. |
| TE02 | 별도 소비자 디렉터리 | 패키징·설치·타입 검사 후 패키지를 가져와 실행한다. | 소비자 환경에서 export와 선언을 해석하고 Node가 BOM 없는 UTF-8 JSON을 저장한다. |
| TE03 | 설치한 브라우저 진입점과 생성된 보고서 | 명시적으로 다운로드한다. | 요청한 이름과 기대 JSON이 담긴 파일을 저장한다. |
