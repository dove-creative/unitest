# TypeScript 환경 및 패키지 테스트 계획

상태-동작 표의 각 행을 테스트에 연결한다. 같은 테스트에서 연관된 계약을 함께 검증할 수 있다.

| ID | 파일 | 테스트 이름 |
| --- | --- | --- |
| TE01 | [browser.test.mjs](../../../../../typescript/tests/browser.test.mjs) | 'runs deterministic selection and async execution in the browser' |
| TE02 | [package.test.mjs](../../../../../typescript/tests/package.test.mjs) | 'installs and verifies the packed package in a separate consumer' |
| TE03 | [package.test.mjs](../../../../../typescript/tests/package.test.mjs) | 'installs and verifies the packed package in a separate consumer' |

## 실행

`typescript/`에서 `npm run build`를 실행한 뒤 아래 명령을 실행한다.

```sh
npm run test:browser
npm run test:package
```
