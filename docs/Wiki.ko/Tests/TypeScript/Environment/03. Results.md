# TypeScript 환경 및 패키지 테스트 결과

## 실행

2026-11-08에 Windows와 Node.js 24.15.0에서 `typescript/`를 기준으로 다음 명령을 실행했다.

```sh
npm run test:browser
npm run test:package
npm run sample -- all
```

| 검증 | 전체 | 통과 | 실패 | 건너뜀 |
| --- | --- | --- | --- | --- |
| Playwright 브라우저 테스트 | 4 | 4 | 0 | 0 |
| 별도 소비 프로젝트의 패키지 테스트 | 1 | 1 | 0 | 0 |
| Node.js 샘플 시나리오 | 6 | 6 | 0 | 0 |
| Chromium 샘플 시나리오 | 6 | 6 | 0 | 0 |

브라우저 테스트 4개는 상위 테스트와 Chromium·Firefox·WebKit 하위 테스트 3개이다.
각 엔진에서 해시·범위·정렬의 고정 검증 16개, 연속 실행 후보 292개와 비동기 경로 재현을 확인했다.
루프백 서버와 브라우저 프로세스를 실행할 수 있는 환경에서 실제 설치 경로를 `PLAYWRIGHT_BROWSERS_PATH`로 지정했다.

패키지 테스트는 별도 임시 디렉터리의 소비 프로젝트에 tarball을 오프라인으로 설치했다.
세 진입점의 타입 선언과 ESM import, Node.js의 BOM 없는 UTF-8 JSON 저장, Chromium의 지정 이름 다운로드를 확인했다.

Chromium에서는 샘플 페이지에서 여섯 시나리오를 선택해 실행했다. 취소 시나리오의 JSON 다운로드에 취소 노드가 포함된 것을 확인했다.
