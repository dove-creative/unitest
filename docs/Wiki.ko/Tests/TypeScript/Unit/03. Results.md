# TypeScript 일반 단위 테스트 결과

## 실행

2026-11-08에 Windows에서 `typescript/`를 기준으로 다음 명령을 실행했다.
Node.js 테스트 러너가 일반 단위 테스트와 UniTest 자체 테스트를 같은 명령에서 발견한다.

```sh
npm run build
npm test
```

| 런타임 | 전체 | 통과 | 실패 | 건너뜀 |
| --- | --- | --- | --- | --- |
| Node.js 22.23.4 | 19 | 19 | 0 | 0 |
| Node.js 24.15.0 | 19 | 19 | 0 | 0 |

일반 단위 테스트 19개는 13개 테스트와 AAA 거부·예상 예외의 하위 사례 6개를 포함한다.
공통 벡터 검증은 해시 9개, 난수 범위 5개, ordinal 정렬 2개의 기대값을 확인했다.
별도 경로 집계는 [UniTest 자체 테스트 결과](../UniTest/03.%20Results.md)에 기록한다.
