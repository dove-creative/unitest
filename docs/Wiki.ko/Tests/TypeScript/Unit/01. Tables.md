# TypeScript 일반 단위 테스트 상태-동작 표

13개 계약 행의 초기 상태, 동작과 기대 결과를 정의한다.

| ID | 상태 | 동작·입력 | 확인하는 결과 |
| --- | --- | --- | --- |
| TU01 | 새 모델 또는 제한된 모델 | 실행 이력을 읽고 실행 한도를 줄인다. | 이력이 누적되며 남은 실행 한도가 늘어나지 않는다. |
| TU02 | 여러 그룹이 있는 TestCase | 포함 또는 제외 선택을 좁힌다. | 새 사례는 다른 그룹을 보존하며 원본을 변경하지 않는다. |
| TU03 | 실행 가능한 Lab | 비동기 AAA 콜백을 정상 완료한다. | 각 단계가 이전 단계의 변경을 확인하고 취소 신호를 받는다. |
| TU04 | 단계를 실행 중인 Lab | Arrange, Act 또는 Assert에서 Promise를 거부한다. | 실패의 원인을 보존하고 이후 단계를 건너뛴다. |
| TU05 | 예상 예외가 지정된 Lab | 일치하는 예외, 다른 예외 또는 예외 없음으로 실행한다. | 일치하는 예외가 발생한 경우에만 Assert를 실행하고 성공한다. |
| TU06 | 병합하거나 확장한 Lab | 메타데이터 및 AAA 콜백을 실행한다. | 병합은 템플릿부터 실행한다. 확장은 원본 Act만 실행하고 역순으로 Assert한다. |
| TU07 | 예상 예외가 여러 개 있는 CompositeLab | 모든 조건 또는 일부 조건에만 일치하는 예외를 던진다. | 모든 선언이 일치해야 한다. 일부만 일치하면 실제 예외를 진단 정보로 보존한다. |
| TU08 | 준비되었거나 일부 탐색한 Project | 탐색 또는 재현하고, 같은 Project를 다시 실행한다. | 실패 정책에 따라 다른 분기를 처리하며, Project는 한 번만 실행한다. |
| TU09 | 시작 전 Project 또는 대기 중인 Act | 외부에서 취소한다. | 사전 취소는 콜백을 건너뛴다. 실행 중 취소는 Act를 기다리고 후속 콜백을 실행하지 않는다. |
| TU10 | 후보를 생성 중인 Project | 후보를 제공한 뒤 또는 모델 생성 중 예외를 던진다. | 기록된 생성기 실패는 이미 생성한 분기와 원인을 보존한다. 모델 생성 실패는 호출자에게 전달한다. |
| TU11 | 실패한 리프가 있는 실행 트리 | 분리·복원하고 다시 실행한 뒤 보고서를 만든다. | 분리 노드의 조상을 복원하고 원본 트리와 기존 보고서를 독립적으로 유지한다. |
| TU12 | 실패했거나 모델 설명 생성이 실패한 트리 | 전체 및 실패 전용 JSON을 생성한다. | 실패 노드와 조상의 원래 ID, 진단 필드 및 원래 문자열을 보존한다. |
| TU13 | 공통 결정적 입력 벡터 | 이력을 해시하고 범위 값을 선택하며 ID를 정렬한다. | 예상 부호 있는 정수, 선택 값, ordinal 정렬 인덱스와 일치한다. |
