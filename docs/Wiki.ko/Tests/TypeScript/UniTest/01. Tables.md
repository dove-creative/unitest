# TypeScript UniTest 자체 테스트 상태-동작 표

4개 계약 행의 초기 상태, 동작과 기대 결과를 정의한다.

| ID | 상태 | 동작·입력 | 확인하는 결과 |
| --- | --- | --- | --- |
| TR01 | 초기 상태의 카운터 모델 | 제한된 깊이까지 두 Lab을 탐색한다. | 생성한 모든 경로를 방문하고 분기마다 독립된 모델을 사용한다. |
| TR02 | 선택한 경로를 실행한 모델 | 실행 제한이 있는 경로를 새 모델에서 재현한다. | 재현 결과가 기대 상태와 일치하며 실행 제한으로 후속 생성을 중단한다. |
| TR03 | 공통 후보 벡터가 있는 Project | seed를 사용해 연속 실행한다. | 실행한 경로 수와 선택된 후보 생성 인덱스가 공통 기대값에 일치한다. |
| TR04 | 두 상태 축을 가진 CompactLab 프로젝트 | 조합한 전이와 의도적인 실패를 탐색한다. | 정상 전이가 각 축을 바꾼다. Assert는 잘못된 동작을 발견하고 보고서는 조상을 보존한다. |
