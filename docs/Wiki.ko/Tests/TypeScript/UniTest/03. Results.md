# TypeScript UniTest 자체 테스트 결과

## 실행

2026-11-08에 Windows에서 `typescript/`를 기준으로 다음 명령을 실행했다.
Node.js 테스트 러너가 일반 단위 테스트와 UniTest 자체 테스트를 같은 명령에서 발견한다.

```sh
npm run build
npm test
```

| 런타임 | 전체 | 통과 | 실패 | 건너뜀 |
| --- | --- | --- | --- | --- |
| Node.js 22.23.4 | 4 | 4 | 0 | 0 |
| Node.js 24.15.0 | 4 | 4 | 0 | 0 |

| 검증 범위 | 실행 수 |
| --- | --- |
| 분기 상태 격리와 전체 탐색 | 생성한 경로 6개 |
| 실행 제한과 경로 재현 | 생성한 경로 2개와 명시적으로 재현한 Lab 2개 |
| 조합 전이 및 의도적인 실패 | 생성한 경로 3개 |
| 공통 seed 시나리오 | 고정 시나리오 4개의 후보 292개 |

조합 전이의 의도적인 실패는 검증 대상의 오동작을 발견하는 대조 사례이다.
자체 테스트는 해당 실패와 조상이 리포트에 남는 것을 확인했다.
