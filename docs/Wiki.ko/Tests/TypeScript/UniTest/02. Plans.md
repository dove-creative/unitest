# TypeScript UniTest 자체 테스트 계획

상태-동작 표의 각 행을 테스트에 연결한다. 같은 테스트에서 연관된 계약을 함께 검증할 수 있다.

| ID | 파일 | 테스트 이름 |
| --- | --- | --- |
| TR01 | [recursion.test.mjs](../../../../../typescript/tests/unitest/recursion.test.mjs) | 'explores every generated path with independent models' |
| TR02 | [recursion.test.mjs](../../../../../typescript/tests/unitest/recursion.test.mjs) | 'replays a path and observes an execution limit' |
| TR03 | [selection.test.mjs](../../../../../typescript/tests/unitest/selection.test.mjs) | 'runs every shared seeded path' |
| TR04 | [recursion.test.mjs](../../../../../typescript/tests/unitest/recursion.test.mjs) | 'detects a faulty transition in composed state exploration' |

## 실행

`typescript/`에서 `npm run build`를 실행한 뒤 아래 명령을 실행한다.

```sh
node --test tests/unitest/*.test.mjs
```
